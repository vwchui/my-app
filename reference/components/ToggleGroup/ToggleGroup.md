# ToggleGroup

**Import:** `import { ToggleGroup } from "@walmart/ld-kit"`
**Category:** components
**Intent:** Group of Toggle buttons with single- or multiple-selection mode (type), sharing variant/size

## Composition

`ToggleGroup` is part of a compound component. Use together with: `ToggleGroupItem`.

All pieces import from the same path (`@walmart/ld-kit`). See each sibling's `.md` for its API.

## Props

- `variant`: "default" | "outline"
- `size`: "small" | "medium" | "large" | "sm" | "lg"
- `children`: ReactNode
