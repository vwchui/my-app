# CollapsibleTrigger

**Import:** `import { CollapsibleTrigger } from "@walmart/ld-kit"`
**Category:** components
**Intent:** Headless expand/collapse primitive (Collapsible + Trigger + Content) — manages open state only, no styling

## Composition

`CollapsibleTrigger` is part of a compound component. Use together with: `CollapsibleContent`, `Collapsible`.

All pieces import from the same path (`@walmart/ld-kit`). See each sibling's `.md` for its API.
