# useSnackbar

**Import:** `import { useSnackbar } from "@walmart/ld-kit"`
**Category:** components · React hook
**Intent:** Snackbars provide brief messages at the bottom of the screen regarding app processes.

## Signature

```ts
useSnackbar()
```

## Options

_(takes no arguments)_

## Usage notes

Snackbars provide brief messages at the bottom of the screen regarding app processes. Snackbars contain brief text directly related to the operation performed. They may contain an action, but no icons.
