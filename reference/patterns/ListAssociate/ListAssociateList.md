# ListAssociateList

**Import:** `import { ListAssociateList } from "@walmart/ld-kit"`

**Intent:** List pattern for associate/scheduling lists — adds avatar, monitoring section, attendance tags. Use ListAssociateList + ListAssociateItem

`ListAssociateList` is part of a compound component. Use together with: `ListAssociate`, `ListAssociateItem`.
