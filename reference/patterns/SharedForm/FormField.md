# FormField

**Import:** `import { FormField } from "@walmart/ld-kit"`
**Category:** patterns

## Composition

`FormField` is part of a compound component. Use together with: `Form`, `FormItem`, `SharedFormLabel`, `FormControl`, `FormDescription`, `FormMessage`.

All pieces import from the same path (`@walmart/ld-kit`). See each sibling's `.md` for its API.

- `children`: ReactNode (required)
- `name`: string (required)
- `rules`: ValidationRules
