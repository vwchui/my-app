# FormControl

**Import:** `import { FormControl } from "@walmart/ld-kit"`
**Category:** patterns

## Composition

`FormControl` is part of a compound component. Use together with: `Form`, `FormField`, `FormItem`, `SharedFormLabel`, `FormDescription`, `FormMessage`.

All pieces import from the same path (`@walmart/ld-kit`). See each sibling's `.md` for its API.
